OneFeed 隐私政策

生效日期：2026 年 8 月 26 日适用版本：{{VERSION}}

概述

OneFeed 是一款将受支持网站的信息流重新排版为统一阅读界面的浏览器扩展。本政策说明扩展在当前版本中如何处理数据。当前版本支持微博、X、小红书、Reddit、知乎、Hacker News、Linux DO、V2EX 与 36氪；未来新增网站支持时会同步更新本政策和相应权限说明。

处理的数据

为了生成统一信息流和受支持的评论阅读界面，扩展会在用户访问受支持网站时读取当前页面已经展示的内容，包括标题、正文、评论、回复、作者公开信息、图片、互动数量、发布时间和内容链接。

扩展还会使用 chrome.storage.local 在用户设备上保存统一信息流的启用状态、主题偏好、顶部网站显隐与顺序、信息流及详情页图片显示偏好、最近使用的平台、展示过滤规则，以及已打开信息流条目的本地标识。

数据用途

页面内容仅用于：

  • 在用户当前页面中生成统一阅读界面；
  • 在受支持的文章详情中统一展示评论与回复；
  • 支持图片预览和原页面互动跳转；
  • 对同一页面中的信息流条目进行本地去重；
  • 在统一阅读界面中标记用户已经打开过的条目；
  • 按用户设置的已读状态、关键词、作者、平台和内容类型规则在本地过滤展示内容；
  • 按用户设置调整统一阅读界面的顶部网站顺序，并控制信息流与详情页是否展示内容图片。

数据传输与共享

当前版本不会将页面内容、浏览记录或扩展设置发送给开发者服务器或第三方，不出售用户数据，也不将数据用于广告、信用评估或与扩展核心功能无关的用途。

所有页面解析、内容清洗和界面渲染均在用户浏览器本地完成。

数据保存与删除

扩展不会建立云端用户数据库。启用状态、主题偏好、顶部网站及图片显示偏好、最近使用的平台、展示过滤规则和已打开条目标识保存在浏览器的扩展本地存储中。用户可以通过卸载扩展清除这些数据，也可以在 Chrome 的扩展管理页面中清除扩展数据。

权限说明

  • storage：在本地保存启用状态、主题偏好、顶部网站及图片显示偏好、最近使用的平台、展示过滤规则和已打开条目标识。
  • 微博：读取并重新排版用户当前打开的微博热门信息流、受支持的单条微博详情与内容检索结果。
  • X：读取并重新排版用户当前打开的 X 首页时间线及其受支持频道。
  • 小红书：读取并重新排版用户当前打开的小红书发现页、内容频道及受支持的笔记详情。
  • Reddit：读取并重新排版用户当前打开的 Reddit 首页、排序页和社区信息流。
  • 知乎：读取并重新排版用户当前打开的知乎信息流、问题与回答、回答评论与回复，以及受支持的专栏文章详情页。
  • Hacker News：读取并重新排版用户当前打开的新闻、问答、展示与招聘列表，并在本地加载公开分页内容。
  • Linux DO：读取并重新排版用户当前打开的话题列表和主题回复页面。
  • V2EX：读取并重新排版用户当前打开的主题列表和主题回复页面。
  • 36氪：读取并重新排版用户当前打开的信息流和文章详情页。

扩展不会在上述受支持网站之外的页面运行。

政策变更

如果未来版本增加云端同步、AI 分析或其他需要传输数据的功能，本政策会在功能上线前更新，并按照适用要求向用户提供明确披露和选择。

联系方式

如对本政策或扩展的数据处理方式有疑问，请通过项目的 GitHub Issues 联系开发者。
