# 微信读书章节页展示

章节阅读页隐藏作者栏，包括占位头像、署名和附加信息，以突出书名、章节标题与正文。图书列表等选书场景继续解析并展示作者。

`ArticleDetail.author` 接受作者对象或 `false`。微信读书章节适配器返回 `author: false`，详情组件跳过整个作者栏；其他平台继续传入作者对象，保持原有展示。`false` 也会隐藏作者栏内的时间和操作，使用它的适配器不应将必要操作放在此处。

章节标题由正文承载：正文已有与当前章节名一致的标题时保留，否则在正文前补充二级标题。标题文本经过空白归一化比较，补充标题使用纯文本创建，避免引入 HTML。分页与原站章节切换逻辑保持原样。
