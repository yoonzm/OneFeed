# OneFeed 商店信息（简体中文）

## 基本信息

- **名称**：OneFeed
- **简短说明**：将受支持网站的信息流重新排版为专注、统一、可随时关闭的阅读界面。
- **推荐分类**：效率工具
- **语言**：简体中文
- **版本**：0.1.0

## 详细说明

OneFeed 面向多平台信息流，将受支持网站的内容转换为简洁、一致的 Focus Paper 阅读界面，帮助你减少页面噪音，把注意力留给内容本身。`0.1.0` 版本支持知乎、Twitter/X、V2EX 与 Linux DO 信息流。

当前版本提供：

- 重新排版知乎、Twitter/X、V2EX 与 Linux DO 信息流，以及知乎问题/回答/专栏和 V2EX 主题详情；
- 统一展示标题、作者、正文摘要、图片和互动数量；
- 支持图片预览和原页面点赞、评论跳转；
- 支持目标网站的信息流继续加载；
- 可从统一视图立即返回原页面；
- 可通过扩展 Popup 随时重新开启；
- 所有页面解析和渲染均在浏览器本地完成。

OneFeed 是独立开发的第三方扩展，与知乎、X Corp.、V2EX、Linux DO 及其关联方不存在隶属、授权或背书关系。

## 单一用途说明

读取用户当前打开的受支持网站信息流，并在本地将其重新排版为低干扰的统一阅读界面。

## 权限说明

### storage

用于在用户设备本地保存统一信息流的启用状态和主题偏好。

### 受支持网站访问

对 `zhihu.com`、`x.com`、`twitter.com`、`v2ex.com` 和 `linux.do` 的访问权限，仅用于读取用户当前打开的信息流、知乎问题/回答/专栏和 V2EX 主题回复，生成统一阅读界面，并代理用户主动触发的原页面互动。扩展不会在这些受支持网站之外运行。

## 数据披露建议

- **处理的数据类型**：网站内容。
- **处理方式**：仅在浏览器本地处理。
- **数据传输**：不发送给开发者服务器或第三方。
- **广告用途**：无。
- **数据出售**：无。

最终选项应以提交时 Chrome Web Store Privacy 页面显示的实际字段为准，并与 `docs/Privacy_Policy.md` 保持一致。

## 测试说明

1. 安装扩展并打开 `https://www.v2ex.com/`，该站点无需测试账号即可查看公开信息流。
2. 扩展会将首页信息流显示为 Focus Paper 阅读界面。
3. 点击顶部“查看原页面”可立即恢复原页面。
4. 点击 Chrome 工具栏中的 OneFeed 图标，可重新开启统一信息流。
5. 滚动到列表底部，验证后续内容继续加载。
6. 可另外使用审核人员自己的账号检查知乎、Twitter/X 或 Linux DO 信息流；无需向审核人员提供 OneFeed 账号或密码。

OneFeed 不提供或收集任何目标网站账号凭据。
